# 🤖 ReNamio

ReNamio est un **bot Discord en Python** qui transforme vos pseudos en versions stylisées grâce à l’Unicode.  
Pratique pour donner une identité unique, surprendre vos amis ou personnaliser vos serveurs Discord.  

---

## ✨ Fonctionnalités

- 🔤 Génère plusieurs styles de texte (carrés, gothique, cursive, fullwidth, etc.)
- 🎲 Commande aléatoire : laisse ReNamio choisir pour toi
- 🛠️ Commandes simples via prefix (`!`) ou slash commands
- 👤 Peut renommer automatiquement un membre (si le bot a la permission)
- 📜 Extensible : facile d’ajouter de nouveaux styles
